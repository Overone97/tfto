# tfto

Auto-battler 2D inspiré de Teamfight Tactics, pensé pour grandir proprement par itérations.

## Vision

Construire un prototype lisible, extensible et data-driven autour de 6 piliers :
- grille de combat
- unités
- combat automatique
- shop et économie
- synergies et progression
- boucle de partie

## Principes du repo

- architecture modulaire
- logique de jeu séparée du rendu
- contenu piloté par des données
- fonctionnalités ajoutées par étapes courtes et testables
- une PR par bloc de progression

## Roadmap initiale

### Phase 1
- fondation technique
- grille
- unités data-driven
- combat auto minimal

### Phase 2
- shop
- bench
- fusion
- rounds

### Phase 3
- synergies
- compétences
- IA simple
- polish UI
